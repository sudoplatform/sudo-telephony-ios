SudoTelephonyClient

public protocol SudoTelephonyClient : AnyObject

The consumer-facing API for the Sudo Telephony SDK.

Consumers should code to this protocol, not to the concrete DefaultSudoTelephonyClient.

Sign-In Delegate

  • setSignInDelegate(_:) Asynchronous

    Set a delegate to sign the user in when an operation is attempted while they aren’t signed in, so an app can launch without waiting to sign in first.

    When set, every operation except subscriptions and the on-device key operations (reset(), exportKeys(), importKeys(archiveData:)) first checks whether the user is signed in, and if not calls the delegate’s signIn(). If signIn() throws, the error is passed to the caller and the operation doesn’t run.

    Declaration

    Swift

    func setSignInDelegate(_ delegate: SudoPlatformSignInDelegate?) async

    Parameters

    delegate

    The delegate, or nil to stop checking.

Lifecycle

  • reset()

    Remove all on-device key material held by the SDK.

    Call when the user signs out or resets, to tear down local keys. Per-number keys are not deleted on deprovision; key lifetime is tied to this reset, in line with the platform convention.

    Throws

    SudoTelephonyError if the removal fails.

    Declaration

    Swift

    func reset() throws
  • exportKeys()

    Export the SDK’s cryptographic keys to a portable key archive.

    Use this to move a user’s message-sealing keys to another device or to back them up before a reinstall, so retained sealed messages remain readable. The returned data contains private key material and must be stored securely.

    Throws

    SudoTelephonyError if the export fails.

    Declaration

    Swift

    Return Value

    The serialized key archive.
