DefaultSudoTelephonyNotificationFilterClient

public final class DefaultSudoTelephonyNotificationFilterClient : SudoNotificationFilterClient

Describes the telephony service’s push notification filter fields to the notification SDK.

Pass an instance to DefaultSudoNotificationClient so the app can filter telephony pushes, for example with the setTelephonyNotifications extensions on NotificationConfiguration.
