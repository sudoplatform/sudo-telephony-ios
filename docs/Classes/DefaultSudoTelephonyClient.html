DefaultSudoTelephonyClient

public final class DefaultSudoTelephonyClient : SudoTelephonyClient

The default SudoTelephonyClient implementation and composition root.

Each public method is a thin adapter: it generates the relevant use case from the UseCaseFactory and awaits its result. No business logic lives in the client.

    Parameters

    keyNamespace

    Namespace isolating this SDK’s keys in the keychain. Used only when keyManager is nil, to build the SDK’s own key manager. Defaults to Constants.defaultKeyNamespace.
    userClient

    The user client the app signs in with.
    keyManager

    An optional caller-supplied SudoKeyManager to back on-device key generation, storage, and unsealing. Leave nil (the default) to let the SDK build a DefaultSudoKeyManager from keyNamespace.
    config

    Options for the client’s behaviour, such as whether every phone number shares one key pair.
