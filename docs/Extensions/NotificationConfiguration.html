Methods

  • initTelephonyNotifications()

    Return a copy of this configuration set up to receive telephony service notifications.

    The returned configuration keeps every other service’s rules first, in their current order. They are followed by a rule that disables telephony notification types the SDK doesn’t recognise, then any existing telephony rules in their current order, then a catch-all rule that enables every other telephony notification. Calling it again on its own result returns an equal configuration.

    Once every Sudo Platform SDK has updated the configuration, pass it to SudoNotificationClient.setNotificationConfiguration to apply it.

    Declaration

    Swift

    func initTelephonyNotifications() -> NotificationConfiguration

    Return Value

    A new configuration with the telephony default rules in place.

  • setTelephonyNotifications(forPhoneNumberId:enabled:)

    Return a copy of this configuration with telephony service notifications enabled or disabled for one phone number.

    Any existing rule for this phone number ID is removed. When enabled is false, a rule disabling notifications for the phone number is added after the other telephony rules and before the catch-all rule that enables everything else. Other services’ rules, and telephony rules for other IDs, are kept in their current order, and the telephony default rules are put in place as by initTelephonyNotifications(). Enabling a phone number that isn’t disabled changes nothing.

    Once every Sudo Platform SDK has updated the configuration, pass it to SudoNotificationClient.setNotificationConfiguration to apply it.
